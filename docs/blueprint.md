# **App Name**: EquipTrack

## Core Features:

- Status Dashboard: Display a dashboard with summaries of equipment status (total, checked, unchecked, good, attention, broken).
- Equipment data table: Present equipment data in a tabular format showing equipment ID, location and current status.
- Log Out: Allow the user to log out.
- Location Display: Display the location name for each equipment item.
- Operator Management: Display a list of operators.
- Anomaly Detection: Suggest which fields in the report may need closer inspection using an AI tool.

## Style Guidelines:

- Primary color: Dark slate blue (#483D8B), conveying a sense of professionalism and order.
- Background color: Almost-black (#121212) to provide contrast, in line with the dark color scheme suggested by the image.
- Accent color: Electric purple (#BF55EC) to highlight key interactive elements.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text.
- Use simple, clear icons for equipment status and navigation.  Use an outline style.
- Employ a card-based layout for dashboard summaries, arranged in a responsive grid.
- Use subtle fade-in animations when data loads or when equipment status changes.
